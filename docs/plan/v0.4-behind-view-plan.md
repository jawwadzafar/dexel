## Non-negotiables (from the PDF, restated so no wave forgets)

1. **Pure idle companion.** No meters, no hunger/energy, no maintenance, no
   death. (Genre lock, user's explicit words.)
2. **Behind-the-shoulder view.** Hooded developer seen FROM BEHIND, centered;
   the monitor FACES THE CAMERA and shows live green-on-dark terminal lines
   drawn at runtime. The old side-view scene is superseded.
3. **Store is a MODAL** — not a strip, not a sidebar. Retro-OS window over
   the scene: title "DEV STORE & CUSTOMIZATION" + close X, "Total Dev Cash",
   left category list (Hoodie / Chair / Desk Items / Room-Wall / Robot
   Buddy), scrollable item grid with [Buy] / [Equip] / [✓ Equipped], item
   preview pane. Opened by a clickable [Store] button in the title bar AND a
   key; closed by X / Esc.
4. **Own-many / equip-one.** Buying and wearing are separate. Style AND
   color per item; colors are runtime tints over grayscale-authored regions
   (N colors must not require N sprites).
5. **Decluttered layout** (the user rejected the busy header): title bar
   ("dev companion ●" + [Store]), scene, bottom-left sprint panel (name +
   progress bar + "N / M units"), bottom-right status ticker (game-flavor
   lines only — NEVER real user data; the real activity line per ADR 0009
   stays separate and truthful).
6. **Honest mechanics stand** (ADR 0010): Coding requires recent keystrokes;
   mouse alone never shows Coding; OnBreak/AFK (~30s) only from genuine
   global idleness; the idle clock freezes when the source is blind.
7. **Deferred to the Go variant, explicitly NOT this game:** the AI-agent
   layer (Ollama summaries/chat), Wails/web dual-mode, WebSockets.

## Known risks, written down so they don't resurface as surprises

- **macOS behavior is field-tested only by the user.** The permissionless
  capture (ADR 0010) type-checks against aarch64-apple-darwin but has never
  executed on a Mac. First mac run after Wave 2 must check: typing anywhere
  moves the bar; minimizing does NOT flip to OnBreak; the startup log names
  the GLOBAL source.
- **Mouse-clickable UI is brand new** — the game was keyboard-only. Bevy UI
  Interaction components; W2-C's spec section covers hit-testing and hover.
- **Save migration** from `upgrades: BTreeMap<String,u8>` tiers to
  own/equip — W1-B specs it; W3-A audits it; nobody loses coins or items.
- **The old side-view sprite set** becomes dead the moment W2 lands; the
  generator keeps only what manifest v2 lists. Deleting art is correct here,
  not waste — it's all regenerable code.
